# 判官规则（吃过亏，写死）

## 铁律

**DAA4（以及任何角色扮演专用模型）不能当判官。**

它只有「扮演莫妮卡」这一个用途，没有评测能力。拿它给答案打分，
等于把「它自己会不会这么说」当成「什么算好」——这不是评测，是回音。
2026-10-23 我用它判过「润色器 vs 编剧直出」，那组 65% 的结论已作废。

同理，**不能**用某个模型判它自己的输出却不声明。可以这样用，但必须写明偏向方向，
并且把它当成「对某一方更不利的条件下仍然输/赢」的保守证据。

## 可用的判官

| 判官 | 用途 | 声明 |
|---|---|---|
| `strong`（deepseek-v4.1-flash，通用强模型） | 风格盲评、语义复核、自动分 | 判自家输出时偏向自己，需声明 |
| 用户指定的其他通用模型 | 同上 | 在 `configs/private.yaml` 加 profile 即可 |
| 人 | 官方基准 V2 的最终分 | 唯一可与 DAA2(66)/DAA3(90) 并列的口径 |

## 各判据该用谁

| 判据 | 判官 | 为什么 |
|---|---|---|
| 语义保真（有没有改意思） | `strong` + 机械闸门 | 校验任务，比生成简单，同族模型够用 |
| 风格盲评（谁更像莫妮卡） | `strong`，**声明自偏好** | 没有更好的自动仪器；差异 <0.05 不下结论 |
| 官方基准 V2 分数 | **人** | 细则原文就写着「仍然是主观的测试」 |
| 标签序列 / 数字 / 方向 | **正则**，不用模型 | 能机械判的绝不问模型 |

## 关于「用 DAA4 当判官」的那次实验

`tools/compare_direct.py --judge maica` 已删除。同一批答案改用 `strong` 重判：

| 判官 | 润色器胜率 |
|---|---|
| DAA4（**作废**） | 13/20 = 65% |
| strong（deepseek，**偏向自己的「编剧直出」那一臂**） | **15/20 = 75%** |

后者是更保守的证据：判官偏向对手，润色器仍然赢。所以「最终输出由润色器写」
这个结论**更强**，不是更弱。
