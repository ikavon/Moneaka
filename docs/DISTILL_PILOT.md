# 教师蒸馏试点：结论是**不做**

按 `docs/PLAN_NEXT.md` B.2：先拿 20 条表达指令请求官方 DAA4（`session=-1` 原样透传），
判断它的渲染是否「明显更贴合我们的输入契约」。**答案是没有，而且比我们自己的模型差。**

速率：一分钟一次，20 条跑了 20 分钟（`tools/maica_client.py` 的 `MIN_INTERVAL=60`）。

## 三个数

| 指标 | DAA4（397B-A17B） | 我们的 1.7B（dpo-b） |
|---|---|---|
| 契约通过 | 20/20 = 100% | 206/206 = 100% |
| **标签序列严格遵从** | **18/20 = 90%**（2 例多加了标签） | **204/206 = 99%** |
| 语义保持（同评委） | 3.70 | 3.70 |
| 输出汉字中位 | 25 | 26（真货 25） |
| 与真货字序相似度 | 0.69 | 0.90 |
| 与指令内容相似度 | 0.74 | 0.59 |

**同指令盲评（n=20，正反各一次）：我们 vs DAA4 = 0.600，CI [0.45, 0.74]。**

点估计是我们赢，但下界 0.45 说明**不能断言我们更好**。能确定的是：
**「用 DAA4 当老师能显著提升质量」这个假设没有成立。**

## 为什么会这样（不是它弱，是任务不同）

DAA4 被训练成「**扮演莫妮卡说话**」，不是「**照着别人给的标签序列把内容渲染出来**」。
所以它是零样本在做我们这个任务，而 1.7B 是拿 941 条同任务样本专训过的。

证据：
* 它两次多加了指令里没有的标签（`尴尬 > 微笑` 之后自己补 `[轻松]`；`微笑` 结尾补 `[开心]`）
  ——这是「按自己的角色理解发挥」，正是我们不要的行为。
* 它跟指令内容的相似度 0.74 > 我们的 0.59，说明它更倾向**照抄指令**而不是「演」。
  它把表达指令当成参考资料，而不是当成台词骨架。

## 决策

**阶段 B（大规模蒸馏）不做。** 按 PLAN_NEXT 里写的规则：「试点不合格 → 蒸馏作废，
不投入大批量」。941 条 × 1 分钟 = 16 小时，换不来质量提升，还会把分布往
「照抄指令」那头拽。

`session=-1` 客户端保留（`tools/maica_client.py`），它仍有两个正当用途：
1. 角色设定探针（补 `data/canon/monika_zh.md`）
2. 需要「官方模型在完全相同的 prompt 下会怎么说」时做对照

## 口径说明

n=20 的盲评，CI 宽 ±0.15。**这个试点的结论强度只够「否决一次 16 小时的大投入」，
不够用来宣称「1.7B 打赢了 397B」。** 后者需要更大的样本，而且对项目没有实际价值。
