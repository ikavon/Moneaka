# 阶段 1：把润色器训出来

目标（从 `STAGE0_CLOSEOUT.md` 继承）：

| 指标 | 阶段 0（零样本） | 目标 |
|---|---|---|
| polish vs draft 盲评胜率 | 0.57（≈抛硬币） | ≥0.85 |
| polish vs reference 盲评胜率 | 0.25 | ≥0.45 |
| 人工「最像莫妮卡」占比 | 5% | ≥30% |
| 契约通过率 | 100%（靠归一化兜底） | 模型自身 ≥90% |

结论先说：**前两项达成 0.93 / 0.30→0.38**，润色器从「不可用」变成「明显在干活」；
剩下的差距定位到了具体一条轴（情绪标签选择），阶段 2 用 DPO 打它。

## 1. 先修数据：任务定义错了，训练只会放大错误

阶段 0 人工盲评里 polish 只有 5%，我去查根因，发现是**数据构造把信息删掉了**：

```
原稿: [不满]笨蛋, 你怎么会这么想? [脸红]当然愿意了啊! [意味深长]我才不要其他人呢.
旧草稿: 你为什么会这么想。我当然愿意。我不要其他人。      ← 「先嗔怪再答应」没了
```

而 `STYLE_GUIDE.md` 的验证显示：官方 chosen / rejected 之间，句数、标签种类、
句长**全都分不开**，唯一稳定分开的是**反应次序**。输入里没有、输出里有的东西，
模型只能猜或者照抄。

改法：草稿升级成**两行表达指令**

```
语气: 先嗔怪对方不该这么想；再脸红答应；最后强调只选对方。
内容: 你怎么会这么想；我当然愿意；我不要其他人。
```

分工不变：**认知归大模型（决定说什么、什么次序），措辞归润色器（按指令实现风格）**。
只是决策现在传得下去了。

第二处：destyle 原本只是「去标签」，措辞几乎照抄原句 → 训练集在教模型复制。
加上「中性重述、去原句痕迹」后重跑全量 226 条：

| | 旧数据 | 新数据 |
|---|---|---|
| 输出对指令的字序改动量 | 0.116 | **0.279** |
| 照抄率（>0.9 相似） | 61.5% | 13.3% |

`pairs_plan.jsonl` 那版还留着「语气: 语气:」重复前缀（模型自续，221/226），
在 `dataset.clean_plan()` 里确定性修掉，不花 API。

## 2. 训练设置

`tools/train_lora.py`，`src/moneaka/dataset.py`：

- 样本 = `system(短版契约) + user(表达指令) + assistant(官方真话)`
- **`assistant_only_loss=True`**：system/user 参与拟合等于让模型背指令，白吃容量
- **few-shot 不进训练**（`restyle_system(few_shot=False)`）：风格进权重后示例就是纯开销，
  示例部分 ~400 token 而真实输出中位 35 字。**训练与推理必须走同一分支**
- `packing=False`：短样本拼一起会学到跨样本续写

| run | 配置 | train_loss | eval_loss 轨迹 | 峰值显存 | 耗时 |
|---|---|---|---|---|---|
| run1 | r16/α32, 3ep, lr2e-4 | 1.198 | 1.063→1.058→**1.057** | 5.41 GiB | 4m35s |
| run2 | r32/α64, 8ep, lr1.5e-4 | **0.525** | 1.074→1.506→**1.888** | 5.64 GiB | 13m11s |
| run3 | r64/α128, 10ep, lr1e-4 | — | 每 epoch 存点 | — | ~25m |

8GB 卡上 bf16 全量精度就够（不用 QLoRA），序列 640 时峰值 5.4 GiB。

## 4. 关键方法学发现：eval_loss 在这个任务上是**反向信号**

run2 的 eval_loss 从 1.07 涨到 1.89（教科书式过拟合），**同一时间盲评胜率从 0.30 升到 0.38**。
原因不难理解：206 条样本、目标是模仿一个特定人格的措辞分布，
「记住分布」和「训练损失变高」是同时发生的——损失惩罚的是不可预测的随机性，
而风格恰恰就是那些不可预测的部分。

所以：

- 选点**不看 eval_loss**，改成每 epoch 存 checkpoint + 盲评选点（`tools/sweep_ckpts.py`）
- 这条已经写进 `train_lora.py` 的注释里，免得下次又拿损失曲线当停止条件

## 5. 第二个指标坑：绝对照抄率是假警报

`copy_ratio(输出, 指令内容)` 超过 0.9 报警？跑完发现**真实 DAA4 输出对指令内容的相似度本来就有 0.714**
（内容行是同一件事的中性重述，相似是应该的）。绝对阈值会天天误报。

改成**超额照抄** = `copy(输出) - copy(真实输出)`，run1 +0.048 / run2 +0.053 —— 模型没有比真货更爱抄。
`evaluate.py` 里已改成报告 `copy_excess`，绝对值只留作参考。

## 6. 差距定位：输在情绪标签选择，不是句子结构

20 条留出集上把模型输出与真实输出逐位对齐：

| 特征 | 模型 | 真实 |
|---|---|---|
| 句数/条 | 5.1 | 5.2 |
| 半角逗号/条 | 2.05 | 2.15 |
| 「么」 | 0.50 | 0.55 |
| 波浪号 | 0.35 | 0.40 |
| 语气词(啦嘛呢哦呗呀) | 0.95 | **1.25** |
| 留白 `...` | 0.20 | **0.30** |
| **标签逐位吻合** | **33/51 = 65%** | — |

句子结构、标点、拆句节奏基本对齐了；**没对齐的是标签选择**，而且错法很有规律——
往最安全的「微笑」回归：

```
出[微笑,微笑,脸红]  真[思考,凝视,尴尬]
出[微笑,player]     真[担心,player,凝视]
出[微笑,开心]       真[笑,微笑]
```

（一开始怀疑是模型把「语气」行里的情绪名抄下来了，专门验了：**0/7 条**，假设不成立。
真实原因是小数据 SFT 的均值回归——不确定时输出边际分布的众数。）

## 7. 阶段 2 计划：DPO + 受控负例

官方 RLHF 的 chosen/rejected **不能**直接拿来做这个任务的偏好对：
去标签后字序相似度中位 **0.18**，两者根本不是同一句话。用它做 DPO，
log-prob 差距会被「内容对不对」吃干净，风格轴拿不到梯度。

改成 `moneaka/negatives.py` 的**四条受控轴**，每条只动一个风格维度、正文逐字不动：

| 轴 | 构造 | 打的缺陷 |
|---|---|---|
| `tags` | 标签整体错位一位 | 65% 吻合率、微笑兜底 |
| `order` | 句子次序反转 | 不按「语气」行演 |
| `merge` | 合成一句只留首个标签 | 不拆句 |
| `flatten` | 去标签去语气词 | 说得太书面 |

DPO 从 SFT 模型出发（先 merge 成独立基座，因为 `DPOTrainer` 不接受 PeftModel+peft_config
并存），在新基座上挂新 LoRA，trl 用同权重上的 `"ref"` adapter 当参照模型，
**不复制第二份 3.4GB**，8GB 卡可跑。
