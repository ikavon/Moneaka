# 三个臂的原始输出（自己看，不打分）

| 臂 | 做法 |
|---|---|
| **我们** | 编剧出表达指令 → 本地 1.7B 润色器渲染 → 机械闸门 + 语义复核 |
| **朴素 prompt** | deepseek 直接用官方基准那句 prompt（「你叫莫妮卡…」） |
| **精写 prompt** | 同一个人，但给了：角色设定 + 事实卡 + 28 标签白名单 + 5 条真实台词 + 风格要求 |

测试集：206 条留出集里的真人素材（模型没见过）。只列输出，不排序、不评分。

## 附：几个事实（不是分数）

* 标签合法率（输出里的情绪标签是否都在官方 28 词表内）：
  **我们 114/115，精写 prompt 114/115，朴素 prompt 19/115**。
  也就是说，格式这件事不是「必须微调」，而是「提示词必须把白名单写进去」。
* 平均字数：我们 38 / 朴素 39 / 精写 41。
* 精写臂用的是同一个 deepseek，只是 prompt 从「你叫莫妮卡…」升级成
  「人设 + 事实卡 + 标签白名单 + 5 条真实台词 + 风格要求」。

## 2026-10-24 的结论修正

先前 `docs/DESIGN.md` 写过「自创标签只有约束解码或微调能解决」——**这句是错的**。
实测加白名单与 few-shot 后，通用模型的标签合法率与微调模型持平。
两段式剩下的价值在于**风格与可控性**，不在格式。
