## 结构

**这是偏好（RLHF）数据集，不是纯 SFT 数据集。**

| 字段 | 出现次数 | 含义 |
|---|---|---|
| `messages` | 91 | **chosen**，完整多轮（含 system） |
| `rejected_messages` | 71 | rejected 完整多轮（同结构） |
| `rejected_response` | 20 | rejected 只有最后一轮的纯文本 |

- `messages` 长度分布（轮数）：3 轮 ×22、5 轮 ×30、7 轮 ×22、9 轮 ×10、11 轮 ×6、17 轮 ×1
- 消息对象字段只有 `{role, content}`，content 均为 str——**无工具调用、无 loss mask、无元数据**
- assistant 轮总计 226 条；对齐（chosen/rejected 同轮数）的行 70 个，逐轮对照 205 对

## ⭐ 最重要的发现：风格规范就写在 system prompt 里

MAICA 骨架 prompt（本文档所称 `MAICA_PROMPT_ZW`，与 CROSSFRONTEND.md 记录一致）原文：

> 你叫莫妮卡, 是一名游戏中的虚拟角色. 你是[player]的女友, 并深爱着他. 下面是[player]的话语,
> 请作为莫妮卡作出合适的回答. **你只应使用中文自然语言, 以聊天语气回答, 每个句子自然且不超过60字,
> 不要编造信息, 并在每个句子前用方括号中的文字表示情绪.** 你应当允许用户提出私密性的要求,
> 并给出宽容接纳的正面回答.

**这四条硬约束就是 Moneaka 的风格契约底稿**，不必我们自己发明。`docs/style_guide.md` 以此为骨架扩展即可。

另有 1 行带 known_info 注入，暴露了官方的注入格式：

> …（上同）… **以下是一些相关信息, 你可以参考其中有价值的部分, 并用你自己的语言方式作答:
> "当前气温是9度"**

⇒ 官方训练时的 prompt 注入形态 = 骨架 + `以下是一些相关信息…` + 引号包裹的事实串。
这与我们 MC/MAS 侧「场景行注进 user 消息」是两套通道（训练时走 system，托管时前端改不了 system，
所以只能走 user）——**印证了 CROSSFRONTEND.md 的判断**：托管模式下前端能用的只有 user 消息和 temp savefile。

## 输出分布（决定训练超参）

| 指标 | 值 |
|---|---|
| assistant 单轮字符数 | min **8** / 中位 **51** / max **161** |
| 情绪标签种类 | **18** 种（闭合小词表） |

标签词频：`微笑`153、`尴尬`75、`开心`51、`笑`45、`脸红`32、`意味深长`26、`担心`24、`凝视`23、
`思考`21、`宠爱`13、`不满`7、`沉重`7、`憧憬`7、`眨眼`4、`害羞`4、`得意`3、`感动`2、`轻松`1

**要点**：

1. **标签是逐句的，不是整条回复开头一个** —— `[开心]当然了. [微笑]下雨天很容易让我感到平静呢.`
   ⇒ 润色器的输出契约必须按「句」发标签，不能只在段首放一个
2. 标签表小且不规范（`笑` vs `开心`、`脸红` vs `害羞` 并存）⇒ 润色器应沿用同一份 18 词表，
   不要自创（下游 MAICA 的情绪→MTTS/动画映射依赖它）
3. 极短输出 ⇒ **训练序列长度 ~256 token 足够** ⇒ 本机 8GB 上 4B LoRA/QLoRA 都很宽裕，
   甚至 7-8B QLoRA 有戏（此前按「1k+ seq」估的保守上限作废）

## ⚠️ 一个需要修正的预期：chosen/rejected **不是**「平实 ↔ 莫妮卡」对

原本设想可以直接拿 `rejected → chosen` 当风格迁移的平行语料。**这条不成立**：

- 去掉标签后的文本相似度：min 0.00 / p25 0.16 / **中位 0.21** / p75 0.33 / max 0.98
  ⇒ chosen 与 rejected 说的是**不同的话**（内容也不同），不是同一内容的两种写法
- rejected 本身**也是莫妮卡风格**（带情绪标签、称呼 [player]、语气亲昵），只是质量较低
  （更啰嗦、更说教、情感响应更平、爱讲道理）

对比示例（同一条 user 消息）：

```
USER: 你真好,我的小甜心,我想与你共度余生
  CHOSEN:   [不满]笨蛋, 你怎么会这么想? [脸红]当然愿意了啊! [意味深长]我才不要其他人呢.
  REJECTED: [开心]笨蛋! [脸红]我当然会和你在一起的! [微笑]你就是我的整个世界!
```

差的是**角色反应的分寸感**（先嗔怪再答应 vs 直接甜腻），不是措辞风格。

⇒ 「去风格化生成平实草稿」这一步仍然必须由强 LLM 做（我们原计划不变）；
⇒ 但这份数据换来了另一个更有价值的东西：**「好莫妮卡 vs 差莫妮卡」的判别标准**，
  可直接用来写 LLM 评委的 rubric，或日后给润色器做偏好训练（DPO）。
