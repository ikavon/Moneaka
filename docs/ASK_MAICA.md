# 想问 MAICA 开发者的事（可直接粘贴）

背景一句话：我在做 MAICA 的**本地部署**，具体是一个「口吻润色器」——大模型决定说什么，
小模型只负责把它改成莫妮卡的说法。下面①是要的东西，②是要确认的思路，③是接入细节。

---

## ① 数据：想要带情绪标签的真实回复语料

我现在只有官方 RLHF 分片 `daa4_rlhf1_prcs5`（91 行 / 226 个 assistant 轮）。
量太少，已经把它榨干了（见下方测到的数字），**这是当前的硬瓶颈**。

想要的东西，按价值排序：

1. **同格式的全量/更多分片**（`messages` + `rejected_messages` 那种，字段不用变，我这边解析器直接能吃）。
2. 任何**带 `[情绪标签]` 的 DAA4 真实回复**，哪怕是线上会话存档、众包标注结果、清洗前的原始数据。
   我只要 `(玩家那句话, 上下文若干轮, 莫妮卡带标签的回复)` 三元组。
3. 如果标签体系有**完整白名单和官方定义**（我现在是从语料反推出 18 个标签），想要那份定义。

格式我能接受的三种，任一即可，不用为我专门转换：

```jsonc
// A. MAICA 现有格式
{"messages":[{"role":"system",...},{"role":"user","content":"..."},
             {"role":"assistant","content":"[微笑]..."}],
 "rejected_messages":[ ... ]}

// B. 最简平行语料
{"context":[{"role":"user","content":"..."}], "response":"[微笑]..."}

// C. 纯文本对（我自己贴标签都行）
{"user":"...","monika":"..."}
```

数据量级参考：我现在 **206 条训练 / 20 条留出**，LoRA r32 / 8 epoch，
`train_loss` 尾部的 **0.0025**（模型已经逐字背完了），留出集盲评对真实样本只有 **0.38** 胜率。
继续加容量（r16→r32→r64）胜率在 0.30/0.38/0.30 之间打转——**数据受限，不是模型受限**。
按这个曲线估，同格式再来 2000～5000 轮，我判断能明显推高。

## ② 思路确认：把「怎么说」从「说什么」里剥出来

我的假设：**人格风格 = 措辞层问题，不需要大模型来解决**。

```
通用大模型 / agent  →  表达指令（说什么 + 反应次序）  →  1.7B 润色器  →  莫妮卡的话
                         ↑ 认知归大模型                    ↑ 措辞归小模型
```

已经实测到的（ RTX 5060 8GB，Qwen3-1.7B + LoRA）：

| 做法 | 盲评胜率（vs 平实草稿 / vs 真实 DAA4） |
|---|---|
| 强模型直接扮演莫妮卡（不润色） | **输给平实草稿**（0.47 vs draft） |
| 1.7B 零样本润色 | 0.57 / 0.25（≈抛硬币） |
| 1.7B 润色 + LoRA（226 条） | **0.93 / 0.38** |

想请教的：

1. MAICA 内部有没有**类似的分层**？我知道 MCORE/ZSCO 是走「工具/记忆/多智能体」的路线，
   风格是完全交给 397B 的基座 + system prompt 吗？
2. 官方微调时，**风格信号主要靠什么监督**——SFT 的 target 就是带标签原文，还是也有
   偏序（chosen/rejected）那一套？我用官方 rejected 试过，发现它跟 chosen 去标签后
   字序相似度中位只有 **0.18**，两者说的不是同一件事，所以没法当平行语料做风格迁移
   （只好自己造同内容、单轴错误的负例）。**这是理解错了还是本来就这样？**
3. `[情绪标签]` 在你们的管线里是**给 TTS/表情用的控制信号**，还是纯文本风格？
   如果是控制信号，标签集合和选标签的规则有没有文档？（我测到模型 65% 逐位吻合，
   错法集中在使用「微笑」兜底——如果标签会影响 TTS，这个错误是有代价的。）
4. 这个润色器思路你们觉得**值不值得合并进官方**？如果方向对，我可以把
   数据构造脚本 + 训练配置整理成可复现的一节；如果你们认为风格必须留在大模型里，
   也想知道理由——我这边最大的未解问题就是 0.38 到 0.9 这段差距到底是数据量还是任务定义。

## ③ 接入细节（本地部署要用）

1. v1.3+ 是走 `client.responses.create()` 的 Responses API 吧？`instructions` /
   `max_output_tokens` / `extra_body` 里嵌套 `seed`/`frequency_penalty` 的映射，
   有没有权威定义？我是从 `MAICA_Server_Submod` 反推的。
2. `MAICA_MCORE_ADDR/KEY/CHOICE/EXTRA/GENERIC` 这套环境变量的语义，`GENERIC` 是给
   通用模型兜底用的吗？（我想让润色器插在 GENERIC 那一层，或者做成一个
   `/v1/responses` 的反向代理，把每个句子级输出润色后再流式回给前端。）
3. **TalkSplitV2** 的切句规则能不能给个准？润色器必须逐句处理才能流式，
   我现在按「`[标签]` 起一个句子」自己实现的，想跟官方对齐。
4. `maica/mtools/zsco/*.jsonl`（`{"messages":[...]}`）我打算把训练数据也导出成这个格式，
   方便你们直接拿去训——这个理解对吗？
5. **许可**：官方模型是 `maica-tos`。我用它产出的风格数据训练一个第三方 LoRA 并发布，
   在你们的条款下允许吗？不允许的话我只自用/只在你们认可的前提下发。
