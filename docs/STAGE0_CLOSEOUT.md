# 阶段 0 收尾

> 2026-10-22。结论一句话：**润色器必须训练，零样本不可用；而且训练数据本身有设计缺陷，
> 必须先修数据再训。**

## 人类盲测（20 组，四选一 + 最不像）

| 臂 | 最像 | 占比 | 最不像 |
|---|---|---|---|
| draft（平实草稿） | 1 | 5% | 11 |
| **direct（强模型按官方骨架直接扮演）** | **10** | **50%** | 3 |
| **polish（1.7B 零样本润色）** | **1** | **5%** | 5 |
| reference（真实 DAA4） | 8 | 40% | 1 |

`draft` 被 11 次投为「最不像」——地板判定正确，说明表格本身可用。

## 人机一致率（同一批题，每题正反各问）

```
polish vs reference: 人 11% | 评委 22% → 同向 ✅
polish vs draft:     人 50% | 评委 72% → 同向 ✅
polish vs direct:    人  9% | 评委 57% → 分歧 ❌
```

**自动评委能识别烂输出，但高估了 polish。** 结论：评委只做粗筛和趋势，
定胜负以人评为准；`data/human_pref/v1.jsonl`（20 对）是它的留出验证集。

## 三个已被证伪的做法（别再犯）

1. **绝对 0-4 打分**：评委给真实 DAA4 只打 2.50（开思考 2.67），连真货都认不出，没有标尺。
2. **把草稿交给评委看风格**：它会拿「内容接不接得上」当「像不像她」，
   于是照抄草稿也拿高分。已改成盲评（只给玩家原话作语境）。
3. **表面统计当质量指标**：拿官方 225 组 chosen/rejected 检验，
   句数/标签种类/标签密度/平均句长**全都分不开**（2.20 vs 2.33、2.11 vs 2.12）。
   只有问号率 1.78×、感叹号率 1.54×、`[player]`率 0.61× 有区分度。
   ⇒ **好坏之别在「反应选择的次序」，不在措辞表层。**

## 度量方法：只有成对比较站得住

`moneaka duel --calibrate 20`：评委在官方 chosen/rejected 上二选一，
**准确率 88%**（40 次比较，CI95 [0.74, 0.95]，正反各问抵消位置偏差）。

自动评委胜率矩阵（`--sample 20`，n=40/对）：

|  | draft | direct | polish | reference |
|---|---|---|---|---|
| draft | — | 0.53 | 0.42 | 0.17 |
| direct | 0.47 | — | 0.35 | 0.25 |
| polish | 0.57 | 0.65 | — | 0.25 |
| reference | 0.82 | 0.75 | 0.75 | 0.50 |

## ⭐ 修数据比训模型更紧急：去风格化把「分寸感」删掉了

阶段 0 的目标是「让润色器学会先嗔怪再答应」。但看现在的 destyle prompt：

```
2. 删掉这些风格特征: 方括号情绪标签, 昵称与爱称, 语气词…, 反问与娇嗔, 刻意短句堆叠.
1. 保留全部事实、观点、意图、情绪倾向与人际态度   ← 与第 2 条自相矛盾
```

真实例子：

```
原稿: [不满]笨蛋, 你怎么会这么想? [脸红]当然愿意了啊! [意味深长]我才不要其他人呢.
草稿: 你为什么会这么想。我当然愿意。我不要其他人。
```

**「先嗔怪」这个反应次序被删掉了**——草稿里只剩一个中性疑问句。
于是训练对里，输入没有分寸信息、输出有分寸表现，
模型只能靠**猜**或者**照抄**。这正好解释了阶段 0 的两个失败模式：

- 照抄草稿（23/60 逐字相同）：它没被告知该怎么改
- 短草稿时瞎编（人评只拿 5%）：它试图补出分寸，但没有任何依据

而表面统计那条结论（「差别在反应次序」）说明：**分寸必须作为显式信息进入草稿层**，
否则润色器学不到，也不该由它来发明（那是大模型该做的决策——「认知归她」的另一面是
「决策归大模型，措辞归润色器」）。

### 改法：草稿带「表达指令」

destyle 输出改成两行：

```
语气: 先嗔怪玩家不该这么想, 再答应, 最后表示不要别人
内容: 我愿意. 我不要其他人.
```

`语气:` 是**可验证事实的转述**（从原稿的反应次序里读出来的），不是风格装饰。
润色器的任务因此变成「按指令实现措辞」——这是它能学会的；
而「该下什么指令」仍由大模型决定——那是它本来就该做的。

顺带的好处：`direct` 臂与 MC/MAS 侧的 prompt 也能用同一套指令格式，两端不会漂移。

## 阶段 1 目标（人类口径）

| 指标 | 现在 | 目标 |
|---|---|---|
| polish vs draft（人评） | 5% : 5% → 平手 | polish 明显胜出 |
| polish vs reference（人评） | 1 : 8 | **≥ 4 : 8** |
| 逐字照抄率 | 23/60 = 38% | **≤ 10%**（照抄=没干活） |
| 契约通过率（归一化后） | 100% | 100% |
| 自动评委 polish vs reference | 22% | ≥ 40% |

照抄率是新加的硬指标——**没有它，「style 涨了」可能只是归一化的功劳**。
