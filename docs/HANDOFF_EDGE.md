# Moneaka：给 MAICA / Edgeinfinity 的材料

一句话：**把「说什么」和「怎么说」拆开**——大模型只产出一条结构化的表达指令，
一个 1.7B 的本地小模型负责把它说成莫妮卡的话。

> 这份文档替代旧的 `docs/ASK_MAICA.md`（那份是 226 条数据时期的，数字已过时）。

## 1. 现在的形态

```
玩家消息 + 记忆/事实卡
        ↓
   [编剧] 任意强模型（我们用 deepseek）      ← 决定说什么、什么情绪
        ↓  plan：「语气: 标签序列」+「内容: 逐段要点」
   ┌────────────────────────────┐
   │  机械校验（回指/设定冲突/能力越界/长度）│  ← 交付前约束编剧
   └────────────────────────────┘
        ↓
   [润色器] Qwen3-1.7B + LoRA（本地产物）    ← 只决定怎么说
        ↓  台词
   ┌────────────────────────────┐
   │  A 机械闸门（标签/数字/方向/语言）      │
   │  B 语义复核（强模型，触发式）           │
   │  标签错→按位重贴；仍不过→直译兜底       │
   └────────────────────────────┘
        ↓
      台词
```

两种交付形态都已跑通：

| 形态 | 接口 | 谁决定说什么 | 状态 |
|---|---|---|---|
| **薄服务** | `POST /polish`，无状态 | 调用方的 agent | ✅ 已跑通 |
| **厚服务** | `POST /v1/chat/completions`，伪装成模型 | 我们这边的编剧 | ✅ 已跑通 |

## 3. 我们踩过的坑，可能对你们也有参考价值

### 3.1 「win 对真人原答」这个指标会奖励抄袭

指令是从真人回复反推出来的，所以**越照抄指令，越容易打平**。
我们把指令改得更贴近原文时，win 从 0.447 涨到 0.53，但语义掉了、抄写率从 0.49 涨到 0.65。
**报 win 必须同时报「与原文的逐字相似度」**，否则会把退化读成进步。

### 3.2 老师蒸馏不划算

拿 DAA4（`session=-1` 原样透传 prompt）当老师，在**同一份表达指令**下：
它的标签遵从 90%（我们 99%），盲评 0.65 输给我们。
原因不是它弱，而是它被训练成「扮演莫妮卡」，不是「照别人给的标签序列渲染内容」——
它会自己补 `[轻松]`、自己换情绪。**这条线我们放弃了。**

### 3.3 长文本是当前的短板

| 指令长度 | 抄写率（与指令的字面重合） |
|---|---|
| ≤30 字 | 0.45 |
| 31~55 字 | 0.51 |
| >55 字 | 0.58 |

真实对话里（文学讨论、学科闲聊）能到 0.75~0.88——**模型改不动散文体长句，只加语气词**。
数据里其实有 31% 的长内容（≥120 字的回答 502 条，MAS 话题包），
但那是「话题 → 长篇独白」，不是「长指令 → 长台词」。**这是我们最想要的数据缺口。**

### 3.4 DPO 无效

挖了 271 对 on-policy 负例做 DPO，三组超参，语义只从 3.59 到 3.55~3.57（噪声内）。
失败原因也查清了：一开始训在**错误的合并基座**上（旧目录被复用），修好后收益归零。
**结论：语义尾巴靠审查兜，不靠偏好优化。**

## 5. 已知限制（诚实清单）

1. **指标不可比**：我们的 win 是对真人原答，不是官方基准的人工分。
2. **自动评分不可信**：同一批答案重复打分会有 ±3 分波动；判官和编剧同族，有自偏好。
3. **长文本弱**：>55 字的指令，模型基本在照抄（0.58~0.88）。
4. **润色器无状态**：看不到历史。跨轮一致性靠指令携带，不靠它记忆。
5. **它不会自己判断情绪**：标签必须由上游给，让它自己选准确率只有 67%（错例全退「微笑」）。
6. **服务单卡串行**：8GB 只能跑一份，多实例要多个进程/机器。
